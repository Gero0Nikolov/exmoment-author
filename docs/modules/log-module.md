# Log Module

## Scope

Log module provides reusable structured logging and admin visibility.

## Components

- `modules/log/LogService.php`
- `modules/log/LogAdminController.php`
- `modules/log/views/admin-log.php`

## Responsibilities

- Centralize logging calls from runtime modules.
- Render log administration UI.
- Support diagnostics for scheduler, GPT, and jobs execution flows.
