# Used Articles Registry Rollout

## Goal

Roll out and verify the used-articles registry with minimal editorial disruption.

## Rollout Checklist

1. Ensure registry table is created and accessible.
2. Verify write paths from jobs and library workflows.
3. Validate duplicate/exclusion behavior in generation runs.
4. Review logs for write failures and fallback outcomes.
5. Confirm downstream content quality and deduplication expectations.
